# Previsão do Tempo

Aplicação simples de previsão do tempo desenvolvida com HTML, CSS e JavaScript, utilizando a API do OpenWeatherMap para buscar dados climáticos de uma cidade.

## 🚀 Funcionalidades

- Pesquisa da previsão do tempo por cidade
- Exibição da temperatura em graus Celsius
- Exibição do nome da localização pesquisada
- Ícone do clima retornado pela API
- Validação simples para impedir buscas muito curtas

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- TypeScript
- OpenWeatherMap API

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone <url-do-repositorio>
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd previsao-do-tempo
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar o projeto.

## 🔑 API

Este projeto usa a API da OpenWeatherMap. Para funcionar corretamente, é necessário ter uma chave de API válida.

No arquivo JavaScript, a chave atual já está configurada, mas você pode trocar por outra se preferir.
